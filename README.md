# 🛒 Vanilla JS E-Commerce App

A modular single-page e-commerce application built using **vanilla JavaScript**.It provides a complete shopping experience including product browsing, filtering, cart management,checkout flow and order confirmation..

---

## 🚀 Features

### 🛍️ Product System
- Product listing page
- Product details page
- Dynamic routing between pages

### 🛒 Cart
- Add/remove products
- Update quantities
- View cart summary

### 💳 Checkout Flow
- Address validation
- Card validation
- Promo code support
- Order placement
- Order confirmation page

---

## 🔎 Search & Filters

### Header Search
- Search products by name

### Sidebar Filters
- Filter by category
- Sort products (price, popularity, etc.)
- Price range filter

---

## 🧭 Routing

Custom client-side routing handles navigation between:
- Products page
- Product details page
- Cart page
- Checkout page
- Order confirmation page

---

## 🧠 Validation Logic

- **Address validation** → ensures required fields are filled
- **Card validation** → validates payment input format
- **Promo code validation** → applies discounts if valid


---

## ⚡ How to Run

1. Clone the repository   
2. Open `index.html` in your browser  


---
## 🧩 Architecture Highlights
- Feature-based modular structure
- Separation of UI, business logic and services
- Service-based checkout and promo logic
- Custom routing without page reloads
- Reusable validation functions
- Clean and readable naming conventions

---

## 📌 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
